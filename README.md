# StenyxLab v0.1

Simulador de capacidad y cuellos de botella para procesos productivos.

Este repositorio contendrá una herramienta web estática desarrollada con HTML, CSS y JavaScript.

## Objetivo

Permitir al usuario calcular la capacidad diaria de un proceso productivo, identificar el cuello de botella y comparar la capacidad del sistema contra una demanda diaria objetivo.
